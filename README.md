# terraform-github

Organization members and teams, and branch and tag rules for every `tloi-dalat` repository, as code. Atlantis
runs it: comment `atlantis plan` on a PR, get an `sre` approval, comment `atlantis apply`; Atlantis applies and merges.

- `docs/members.md`: who is in the organization and its teams
- `docs/rules.md`: profiles, checks, adding a repository
